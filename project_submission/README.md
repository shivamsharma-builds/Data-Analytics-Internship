# IBM HR Employee Attrition Analytics

An end-to-end data analytics and machine learning project using the [IBM HR Employee Attrition Analysis dataset on Kaggle](https://www.kaggle.com/datasets/nibeditasahu/ibm-hr-employee-attrition-analysis).

The project adapts the supplied submission roadmap from e-commerce to workforce retention. It cleans the 1,470-row, 35-field HR dataset, explores attrition patterns, trains an explainable Logistic Regression baseline, assigns employee risk tiers, creates a Word report and PowerPoint deck, and provides an interactive dashboard.

## What is included

- `run_pipeline.py` — reproducible cleaning, EDA, model training, evaluation, and employee risk scoring.
- `IBM_HR_Attrition_Analytics.ipynb` — notebook version of the pipeline.
- `generate_report.py` — creates the Word report after the pipeline has run.
- `generate_presentation.py` — creates a PowerPoint summary after the pipeline has run.
- `requirements.txt` — pinned Python dependencies.
- `data/IBM HR Employee Attrition Data.csv` — the downloaded Kaggle source file.
- `outputs/` — generated figures, cleaned data, model metrics, and risk scores.
- `reports/` — generated `.docx` and `.pptx` submission assets.

## Dashboard

The web dashboard is in `artifacts/hr-attrition-analytics/`. It loads the same bundled CSV and provides:

- Workforce population and historical attrition KPIs.
- Department, role, overtime, satisfaction, and risk-tier views.
- Transparent analytical prioritization score with signals.
- Searchable and paginated employee risk table.
- Cross-dashboard filters, CSV export per chart, print/PDF, dark mode, and manual/5-minute-minimum refresh controls.

The score is a directional analytical aid. It is not a causal explanation, medical assessment, or employment decision.

## Dataset summary

| Item | Value |
| --- | ---: |
| Records | 1,470 |
| Source fields | 35 |
| Observed attrition | 237 employees |
| Observed attrition rate | 16.12% |
| Missing values in source | 0 |

The most important descriptive pattern is overtime exposure: employees marked `OverTime = Yes` have a materially higher observed attrition rate than employees marked `No`. The highest observed job-role rate is among Sales Representatives, a small group that should be interpreted with its sample size in mind.

## Methodology

1. **Cleaning:** remove duplicate rows, normalize the UTF-8 BOM in the first header, trim categorical values, coerce numeric fields, and fill any future missing numeric/categorical values explicitly.
2. **EDA:** produce five charts using observation → insight → hypothesis → recommendation framing.
3. **Leakage control:** model inputs exclude `Attrition`, and evaluation is performed on a stratified held-out test set.
4. **Model:** standardized numeric inputs and one-hot encoded categorical inputs feed a class-balanced Logistic Regression model.
5. **Risk scoring:** use predicted churn probability thresholds of `<40%` Low, `40–70%` Medium, and `>70%` High, following the supplied guide. Treat these as review queues, not automatic action.

## Reproducibility notes

- Random seed: `42`.
- Test split: 20%, stratified by attrition label.
- Target: `Attrition == "Yes"`.
- All reported metrics are generated by `run_pipeline.py` and written to `outputs/model_metrics.json`.
